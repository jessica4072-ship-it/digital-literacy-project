## Module Summaries
### Module 1: Digital Literacy Basics
This module explains the meaning of digital literacy and why it is important. It focuses on safe internet use, digital tools, and responsible behavior online.

### Module 2: Digital Identity & Portfolio
This module focuses on creating a professional online presence using platforms like GitHub and LinkedIn. It highlights the importance of honesty and authenticity in digital profiles.

### Module 3: Collaboration & Platforms
This module explains how digital tools like Google Docs and coding platforms help in collaboration. It also highlights issues like unequal participation and dependency.

### Module 4: Communication & Etiquette
This module focuses on professional communication, especially email writing. It teaches the importance of tone, structure, and respectful communication.

### Module 5: Cyber Awareness
This module explains cyber threats like phishing and online fraud. It emphasizes the importance of being careful and verifying information before taking action.
